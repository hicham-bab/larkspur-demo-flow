# Larkspur demo flow

Slide-style page for the joint Fivetran + dbt + Snowflake demo on Larkspur Financial (synthetic data).

Open `index.html`, or the GitHub Pages site. Arrow keys or space to move, N for speaker notes, P to print.

The project behind the demo, with its data and a one-shot Snowflake setup script, is public at
[hicham-bab/larkspur-financial-dbt-lab](https://github.com/hicham-bab/larkspur-financial-dbt-lab).
